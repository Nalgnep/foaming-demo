    知识

    体系参数卡与工艺窗口速查

    来自行业知识收集报告（厂商资料 / 专利 / 标准公开来源）。核心纪律：反应性阈值必须绑体系——同一个「凝胶时间」，换个体系，正常范围完全不同。

    体系参数卡

    现场用法：当班杯泡测得的乳白 / 凝胶时间，只和本卡的同体系基线比对；真正要报警的是同体系、同温度下的系统性漂移（如凝胶明显缩短 → 流动距离变短 → 远端空洞风险上升），不是跨体系比绝对值。

    工艺窗口速查（多来源交叉的通用范围）

    参考窗口，非判废线：以上是多来源交叉一致的通用范围，正式判定以本厂体系参数卡与工艺规程为准。填入实测值可看偏离方向；料温、模温、混合压力还能一键写入证据，分数要等再次点「开始推理」才变。

    证据

    第二步：现场证据确认

    每条证据三种状态：命中=确实观察到；未命中=查过了、没有；无数据=还没查。查过没有和没查过，对推理的意义完全不同——这正是老师傅说的「排除证据」。
    杯泡分流试验
    排查第一刀：剖切分型后先打一杯泡。杯泡也异常 → 问题在出枪之前（料 / 配比 / 混合 / 料温）；杯泡正常 → 去查模具 / 排气 / 注料。选定后，推理会给对应一侧的嫌疑 +10 分，并在评分明细里写明理由。

    推理全程在本页面内完成。排序仍用模型第 6、7 节种子分；得分份额不是后验概率。
    过程

    推理链路：引擎是怎么一步步想的

    STEP 1 / 6

    表型识别

    先把缺陷的「长相」定准：是哪一类空洞、长在哪里、什么形态。长相定错，后面全错。

    STEP 2 / 6

    杯泡分流

    先打一杯泡把问题切成两半：杯泡也异常，问题在出枪之前（料/配比/混合/料温）；杯泡正常，去查模具、排气、注料。对应一侧的嫌疑 +10 分。

    STEP 3 / 6

    假设生成

    根据长相列出嫌疑名单——就像老师傅先在脑子里把可能的原因过一遍，一个不落。

    STEP 4 / 6

    证据取证

    拿现场证据逐条对照每个嫌疑：对得上是支持，对不上是排除，没查的是缺口。

    STEP 5 / 6

    评分排序

    每个嫌疑先按历史占比给一个起步分（先验分），支持证据加分，排除证据重扣，算总分排名。

    STEP 6 / 6

    核查推荐

    分数接近分不清时，推荐「下一步先查什么」：专挑成本低、又最能区分前两名嫌疑的检查；还没做杯泡时，杯泡分流试验排第一。

      一、无损检测（5 条）

      NDT-01

      微焦点 X 射线 CT 定量分析 PU 泡沫内部空洞

      结论：微焦点 X 射线 CT 可同时分析 PU 泡沫内部空洞的体积与壁厚，并分析粘接界面不均匀与空洞；切割检查会改变空洞形状或粘接状态，因此宜用无损方式复核。

      数值性质：定性方法（厂商应用实例）　可信度：中（厂商应用笔记）

      适用边界：离线 / 实验室验证用，不等同于整箱在线检测；对剖切结论有争议的案例，优先建议 CT 复核，而非仅凭切割面形态定性。

      来源：岛津微焦点 X 射线 CT 应用实例

      NDT-02

      脉冲 / 锁相红外热像探测泡沫夹层内部空洞与分层

      结论：主动式红外热像中，内部存在空洞或分层时，缺陷上方因边缘效应出现局部高温区；2024 年《红外技术》论文在 1.0 mm 蒙皮泡沫夹层试件上对比了脉冲激励（125 帧）与锁相激励（128 帧）两种算法。

      数值性质：研究方法与试件条件（非冰箱箱体实测）　可信度：高（同行评议期刊论文）

      适用边界：研究对象为软质泡沫夹层复合材料，非冰箱硬泡箱体；机理可作定性参考，整箱应用前须用本厂箱体做验证试验，不得直接套用检出率。

      来源：《红外技术》2024 年论文（PDF）

      NDT-03

      检测手段选择：按缺陷物理特征与深度选，不默认可见光

      结论：可见光成像不足以检出主要表现为温度、光谱 / 材料差异或内部结构的缺陷；脉冲热像结合深度学习可做内部缺陷分割，X 射线成像适用于不透明部件内部的空洞与孔隙；手段选择应跟随缺陷的物理特征与深度。

      数值性质：方法论结论（综述）　可信度：高（综述论文）

      适用边界：通用方法论，适用于核查动作选型：表面缺陷 → 可见光视觉；疑似内部空洞 → 热像筛查或 X 射线 / 超声。

      来源：AI 视觉工业检测综述（MDPI）

      NDT-04

      泡沫 AI 视觉只覆盖表面，内部缺陷仍需超声 / X 射线

      结论：泡沫材料 AI 检测厂商资料明确，内部缺陷（分层、孔隙、内裂）需要超声、X 射线等无损检测；表面视觉仅覆盖表面与轮廓；新兴行业缺陷标准尚在形成，建议早期试样阶段就建样本库与判定基线。

      数值性质：厂商技术资料口径　可信度：中（厂商资料）

      适用边界：用于纠正「AI 视觉全检」的过度宣传；样本库建议可用于回测案例积累。

      重点警示：表面视觉通过 不得作为排除内部空洞的强排除证据；内部空洞的排除证据只能来自剖切、CT、超声或热像复核。表面完好但怀疑内部空洞 / 分层时，先用热像筛查或 CT / 超声，阳性结果仍需剖切或 CT 确认。

      来源：泡沫材料 AI 检测厂商技术资料

      NDT-05

      HMRF-U-Net 无监督分割 PU 泡沫微 CT（2025 预印本）

      结论：KIT 团队 2025 年预印本提出 HMRF-U-Net：无需真值标签即可对 PU 泡沫微 CT 图像实现高精度分割，并提出预训练策略以大幅减少训练分割模型所需的标注数据量。

      数值性质：研究方法（预印本，未经同行评议）　可信度：高（研究机构预印本，标注「未同行评议」）

      适用边界：只是离线泡孔 / 空洞定量分析的技术储备，整箱级应用未经验证，当前不得作为已验证的产线检测手段入库；未来若建 CT 样本库，可借其无监督分割降低标注成本。

      来源：arXiv 预印本 2511.11378

      二、数字化监控（3 条）

      DIG-01

      座椅发泡 CNN 缺陷模型：混合头处传感 + 质量偏差标定

      结论：汽车座椅 PU 发泡研究在混合头最近处装流量、压力、温度传感器采集双组分数据，单次发泡 1.11 秒取均值；缺陷标定以成品质量偏离参考值 ±3% 为界，CNN 缺陷检测准确率 98.33%。

      数值性质：跨域研究数据（汽车座椅泡沫，非冰箱箱体）　可信度：高（同行评议论文）

      重点警示：传感器布点（混合头最近处）与「以质量偏差定义缺陷标签」的思路可迁移，但 ±3% 与 98.33% 不得直接套用于冰箱箱体；冰箱箱体的预警阈值必须用本厂历史数据重标。

      来源：座椅发泡 CNN 研究（MDPI Mathematics）

      DIG-02

      EP4257325 / EP4257327：成像 + 机器学习预测泡沫参数并反馈工艺

      结论：两件欧洲专利提出，发泡中 / 发泡后即刻或切割后、冷却至室温前，用红外或光学成像采集泡沫图像，训练好的机器学习模块对切面泡孔结构做二维分割以预测泡沫参数；另一件据此生成控制信号以调整连续块状泡沫生产工艺参数。

      数值性质：专利（2023 年公开）　可信度：专利文献

      重点警示：这是连续块状泡沫工艺专利，冰箱箱体为模塑间歇工艺；「成像 → 分割 → 参数预测 → 调参」只作远期架构参考，控制信号的具体实现不得照搬，当前仍以离线核查动作为主。

      来源：EP4257325A1（PDF）

      DIG-03

      真空辅助发泡（VAI）细化：减压维持至凝胶形成闭孔泡沫

      结论：EP2386585 细化基线 VAI 条目：腔体减压至少维持到凝胶形成闭孔硬质 PU 泡沫；该体系密度 28–40 kg/m³、平均泡孔直径小于约 250 μm、10 ℃ 平均板温下导热系数小于约 19 mW/m·K（ISO 12939 / DIN 52612）。

      数值性质：专利实施例　可信度：专利文献

      重点警示：该导热数未注明初始 / 长期，且测试方法与国标方法不同，不得与国标方法限值直接比对（详见下方国标锚点修正栏）；密度 / 泡径 / 导热三数仅作该专利体系参照。工艺卡可补记的只有「减压维持至凝胶」这一时序要点。

      来源：EP2386585（EPO 公开文本）

      三、HFO 发泡剂（4 条）

      HFO-01

      Solstice LBA（1233zd）厂商宣称的整机能耗收益

      结论：供应商文章宣称，Solstice LBA 体系泡沫导热优于 245fa 与环戊烷体系，同型号冰箱整机能耗比 245fa 体系低 3%、比环戊烷体系低 7%。

      数值性质：厂商宣称（非独立实测）　可信度：中（供应商文章）

      重点警示：这只是厂商宣称，不得作为本厂能效承诺；换体系论证时可列为宣称收益项，同时标注「须本厂实测」。

      来源：Solstice LBA 供应商文章

      HFO-02

      1233zd / 烃类复配：导热随烃比例上升，高温尺寸稳定性更优

      结论：EP2788415 实施例数据：1233zd 与异戊烷 / 正戊烷 / 环戊烷复配时，初始导热系数随烃类摩尔占比上升而上升（纯 1233zd 最低）；1233zd 复配泡沫在高温环境下的尺寸稳定性比纯烃类泡沫好 50% 以上（专利表述）。

      数值性质：专利实施例　可信度：专利文献

      适用边界：复配比例是导热与尺寸稳定性的权衡变量，换体系时须按比例重建参数卡；复配体系缺陷排查先确认复配比例是否漂移——比例漂移可同时解释导热漂移与高温尺寸问题。

      来源：EP2788415A1（Google Patents）

      HFO-03

      中国冰箱路径判断：环戊烷可能长期保留，HFO 主要面向出口

      结论：行业分析指出，HCFC-141b 在中国加速淘汰后，冰箱、冷柜可能因环戊烷价格相对低而长期继续使用环戊烷 / 环异戊烷体系，HFO 体系产品主要出口至发达国家和地区。

      数值性质：行业分析判断　可信度：中（行业文章）

      适用边界：仅作知识库建设优先级判断：国内线以环戊烷体系为主卡，HFO 体系作出口线备卡；出口线换 HFO 时单独建卡，不得共用阈值。

      来源：行业分析文章（7CF）

      HFO-04

      异构体警示：1233zd(E) 与 1233zd(Z) 不得混用数据
